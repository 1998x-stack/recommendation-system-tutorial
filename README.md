# 推荐系统教程：从原理到工业实践

这套课程围绕一个核心问题组织：如何利用用户、物品与上下文信号，在规模、延迟、体验和业务约束下生成高质量推荐，并用可靠的实验判断它是否真正有效。

- **8 章知识主线**：从推荐问题与经典算法，走到深度学习、Embedding、工程架构、评估和工业案例。
- **28 个实践专题**：覆盖协同过滤、矩阵分解、特征交叉、召回、排序、多任务、实时推荐、冷启动、多模态和 LLM 推荐。
- **5 个独立精讲模块**：提供 Markdown、独立 HTML、Python 示例、原创 SVG 图解和逐条证据清单。

## 运行示例与质量检查

推荐使用 Python 3.11+。五个教学示例只使用标准库：

~~~bash
python -m unittest discover -s tests -v
python scripts/validate_content.py
~~~

安装浏览器验收依赖并运行 Chromium 检查：

~~~bash
pip install -r requirements-dev.txt
python -m playwright install chromium
python scripts/browser_smoke.py --output reports/browser-qa
~~~

浏览器验收覆盖 1440、768、390 和 360 像素视口、打印模式、SVG 尺寸、控制台错误、外部资源请求和至少一个真实交互。CI 未运行或被跳过的项目必须标记为“未验证”，不能写成通过。

## GitHub Pages

静态站点以仓库根目录为发布源，部署工作流监听默认分支 **main**，不依赖 npm 或不存在的转换脚本。首次启用时，请在仓库 **Settings → Pages** 将 Build and deployment 的 Source 设为 **GitHub Actions**。

## 内容质量约定

- 每一页都是独立文章：补足必要背景、定义、假设、公式、示例、边界和参考资料。
- 不依赖读者先看其他页面，不写“讲义介绍了……”一类转述式开头。
- 论文指标必须附数据集、任务、指标口径和原文定位；教学假设与推导结果要明确标注。
- Markdown 与 HTML 的 H1/H2 顺序保持一致；图解有独立 SVG、标题、描述和图注。
- 示例明确区分玩具演示、论文忠实实现和完整基准复现。
